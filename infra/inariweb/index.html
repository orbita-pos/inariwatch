Caddy Reverse Proxy
Automatic TLS via Let's Encrypt. Routes traffic across 5 internal services with zero-config HTTPS and HTTP/2.
🐳
Docker Runtime
Isolated containers per service. Ephemeral environments spin up for E2E fix verification before any merge.
🔄
Go Cron Scheduler
5 internal cron jobs trigger InariWatch routes on schedule — poll, uptime, escalate, deploy-monitor, digest.
🤖
AI Worker (Node.js)
40-turn agentic loop for AI code fixes. Runs on local Docker for ~1ms tool latency — no Vercel timeout.
📡
WebSocket Relay
Real-time bidirectional relay on port 9403, powering Inari Live's live assistant communication.
🦀
eBPF Kernel Agent
Kernel-level observability via eBPF. Monitors processes, network, filesystem, DNS, and TLS — zero instrumentation needed.
